Puts a set on underneath the conversation.

Four moods, each a genuinely different room rather than one preset with a knob
turned:

- **deep** — slow four-to-the-floor, minor, dark. Night, club, late.
- **ambient** — no drums at all, pentatonic, very slow, wide open. Focus, study.
- **bright** — lydian, faster, hats on every beat. Morning, upbeat, sun.
- **drive** — dorian, fastest, sixteenth hats. Running, energy, techno.

Whichever the words point at; `deep` when they point nowhere.

The set decides the key while it plays, and every sound the interface makes
re-tunes to it — the keystroke ticks, the chord when an answer lands, all of it.
That is why this exists here rather than being a music player in a corner. The
tonic stays where the conversation had it and only the mode changes, so starting
a set does not transpose the room out from under whatever was just said.
